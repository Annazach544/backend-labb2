# REST API - Arbetserfarenheter

Detta projekt är en REST-baserad webbtjänst skapad med Node.js, Express och SQLite.

API:et hanterar arbetserfarenheter och stödjer CRUD-operationer med HTTP-metoderna GET, POST, PUT och DELETE.

## Teknologier
- Node.js
- Express
- SQLite
- CORS

## Installation

```bash
npm install
npm run dev
